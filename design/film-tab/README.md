## 세 방향

- **사진 갤러리**: 효과가 적용된 사진을 가로로 크게 보여 주는 목록. 탭하면 전체 예시 화면으로 이동하며 원본 / 필름을 전환한다.
- **카메라 진열장**: 현재 앱의 컴팩트 카메라 아이콘을 활용한 2열 진열. 필름 없음은 별도 행. 탭하면 바텀시트에서 예시와 원본을 전환한다.
- **필름 도감**: 작은 사진·이름·특징의 간결한 목록. 탭하면 원본과 필름을 슬라이더로 비교한다.

공통: `Film.available` 기준 필름 없음 / 빈티지 / 흑백만 노출. 준비중은 제외. 하단 탭은 기록 / 필름 / 설정 순서, 필름 선택 상태. 기존 다크·아이보리 팔레트와 명조 헤드라인을 사용한다.

예시 사진은 프로젝트의 `design/app-store/screens/assets/coffee-window.png`, 카메라 아이콘은 기존 공통 리소스를 사용했다. 브라우저의 흑백·입자·비네팅은 디자인 검토용 근사 표현이며 네이티브 저장 결과와 픽셀 단위로 일치하지 않는다. 실제 구현 시 공통 Film 정의와 저장 렌더러를 사용해야 한다. 필름을 누르는 동작은 소개·예시 보기이며 촬영 필름을 바꾸지 않는다.
