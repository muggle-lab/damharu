# Google Play 최종 등록 이미지

사용자가 확정한 휴대전화 스크린샷은 `01.png`~`04.png` 총 4장이다. 파일 이름 순서대로 등록한다.

- 스크린샷: 1080×1920, RGB PNG, 알파 없음.
- `app-icon-512.png`: 별도로 등록하는 512×512 앱 아이콘.
- `feature-graphic-1024x500.png`: 별도로 등록하는 1024×500 피처 그래픽.
- 2026-11-12: 이전 이미지·중복 ZIP·미리보기·캡처 원본·생성 스크립트·fixture를 제거했다. 위 최종 파일의 내용은 변경하지 않았다.
