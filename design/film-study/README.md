# 필름 5종 검토안 — 2026-10-23

상태: 사용자 검토 대기. 앱에는 적용하지 않음. 필름 없음은 별도 비교 기준이며 제안한 필름은 총 5종이다.

| 후보 | 의도 | 어울리는 장면 | 확인할 점 |
|---|---|---|---|
| 빈티지 | 기존처럼 색은 유지하고 입자·비네팅 강조 | 거리, 일상의 사물 | 어두운 사진의 모서리가 과하게 묻히는지 |
| 온기 | 푸른 채널을 줄여 부드러운 꿀빛 | 카페, 음식, 오후 실내 | 피부·전구 조명이 너무 노래지는지 |
| 청명 | 약한 냉색과 또렷한 대비 | 하늘, 바다, 밝은 야외 | 피부가 차가워지거나 밝은 부분이 날아가는지 |
| 바램 | 검정을 들어 올리고 채도·대비를 낮춤 | 산책, 오래된 공간 | 흐릿한 사진에서 피사체가 묻히는지 |
| 흑백 | 색을 제거하고 명암·입자 강조 | 건축, 그림자, 인물 | 얼굴과 어두운 옷의 디테일이 남는지 |

`preview.html`은 대화용 비교 시안의 원본 조각이다. 같은 입력에 4×5 색상 행렬과 고정 강도의 질감을 적용한다. 촬영 UI나 앱 코드가 아니며 강도 조절·사진 가져오기를 실제 앱에 추가한다는 의미가 아니다. 예시 사진은 기존 AI 생성 스플래시 시안이므로 이미 색이 입혀져 있다. 중립적인 본인 사진으로 추가 비교하는 것이 좋다.

빈티지의 질감 강도(.42 / .72 / .30)는 기존 FilmTexture에서 가져왔다. 이 비교안의 난수·해상도·입자 크기는 네이티브 렌더러와 다르므로 정확한 픽셀 일치를 주장하지 않는다. 새 후보의 행렬 및 질감 수치는 preview.html의 films에 보관했다. 최종 선택 후 commonMain의 정의를 기준으로 iOS 프리뷰·저장 결과부터 맞춘다. 원본을 포함하면 선택지는 6개이며 임시 테스트 필름의 교체 여부는 채택 시 결정한다.

검증: JavaScript 구문 검사 통과, 후보 5종 + 원본 구성 및 파일 크기 확인. 브라우저 실제 렌더링·파일 선택 동작, 앱 빌드·네이티브 픽셀 테스트·실기기 촬영은 미실행.

다음 작업: 사용자가 채택할 후보와 조정할 색감을 결정한 뒤 iOS에 적용하고 피부·실내·야외·저조도에서 비교한다.
