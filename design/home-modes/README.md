# 홈 보기 모드 검토안

2026-10-26 사용자 요청으로 달력 외 3개 모드 제안. 채택 전이며 앱 코드는 변경하지 않았다.

- 사진 갤러리: 기록 있는 날만 3열로 배치. 여러 사진을 빠르게 찾는 용도.
- 메모 타임라인: 날짜·사진·선택적 한 줄 메모를 세로로 배치. 기록을 읽는 용도.
- 한 장 앨범: 큰 사진과 아래 날짜별 썸네일. 홈에서 감상할 사진을 선택하며 기존 상세의 스와이프 제거 결정은 유지.

`source.html`은 대화 내 시안 원본, `preview.html`은 확인용 래퍼. 사진과 메모는 검토용 예시이며 기존 스토어 샘플 사진을 재사용했다. 사진 클릭으로 읽기 전용 상세 미리보기, 앨범 썸네일 선택을 지원한다. 월 선택·모드 메뉴·촬영·설정은 위치 참고용이며 앱 기능에 연결되지 않는다. 타이머도 정적 예시다. 호스트 디자인 설정으로 자동/다크/라이트를 비교할 수 있다.

학습 포인트: 같은 날짜별 기록 데이터를 배치 방식만 바꿔 재사용할 수 있다. 채택 시 commonMain의 보기 상태를 분리하고 기존 저장·플랫폼 카메라 연결을 재사용한다.

검증: JavaScript 구문, 변형 3개, 이미지 내장 및 1 MB 미만 확인. 브라우저의 로컬 파일 접근이 URL 정책으로 거부되어 실제 렌더링·클릭·모바일 폭 검증은 미실행. 앱 빌드·네이티브 구현 검증은 이번 시안 범위 밖.

다음 작업: 모드 선택 후 빈 기록·한 건·다량 기록 상태와 모드 전환 UI를 구체화한다.

## 2026-10-26 채택

사용자가 사진 갤러리·메모 타임라인 적용을 요청했다. 앱의 구현 명세는 `docs/tasks/11-home-view-modes.md`가 기준이며, 한 장 앨범은 이번 적용에서 제외한다. 시안은 최초 검토 기록으로 보존한다.
