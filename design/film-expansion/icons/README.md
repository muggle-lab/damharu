# 추가 후보 필름통 아이콘

2026-11-09 · 아이콘 v1 · 사용자 요청으로 신규 4종 앱 반영

기존 `design/film-cartridges/film-vintage-v2.png`를 참조해 built-in image_gen으로 각각 제작했다. 검정 스풀·실버 테두리·오른쪽 필름 리더·시점·중앙 라벨을 유지하고 라벨 색과 이름을 바꿔 기존 필름통 계열로 맞췄다.

| 파일 | 이름 | 라벨 |
|---|---|---|
| `film-warm-v1.png` | 온기 / WARM | 꿀빛 황금색 |
| `film-clear-v1.png` | 청명 / CLEAR | 차분한 하늘색 |
| `film-fade-v1.png` | 바램 / FADE | 연한 자주색 |
| `film-natural-v1.png` | 내추럴 / NATURAL | 세이지색 |

각각 1254×1254 RGBA PNG, 배경과 필름 구멍에 실제 투명도 포함. 생성 원본을 수정 없이 복사해 보관했다. 프롬프트 전체는 `PROMPTS.md`에 기록했다. 색은 아이콘 구분을 위한 포장 디자인이며 실제 사진에 단색을 덮는다는 의미는 아니다.

검토 자료: 상위 `review.html`의 신규 필름통 섹션. `damharu-film-icons-v1.zip`에 PNG 4개·이 문서·프롬프트를 포함한다.

검증: 네 장의 글자·형태·색·프레이밍 육안 확인 및 파일 규격·알파 확인. 실제 앱의 축소 표시, 밝은 배경 가장자리, VoiceOver와 실기기 확인은 미실행. 후속 적용: 공통 리소스에 512×512로 축소한 PNG 4종을 반영했다. 원본은 이 폴더에 유지한다. 최신 앱 검증 결과는 docs/TASKS.md 참고.
