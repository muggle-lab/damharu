# 담하루

사진 한 장이면, 오늘의 기록은 끝.

개인용 사진 일기 앱. KMP(Kotlin Multiplatform)와 CMP(Compose Multiplatform)를 학습하며 iOS부터 구현하고, 이후 Android를 구현한다.

## 현재 상태

01–08 구현: 홈 달력 → 커스텀 카메라 → 촬영 즉시 저장 흐름, 로컬 저장, 기록 상세와 한 줄 메모를 iOS와 Android에 연결했다. 사진 선택기·필터·과거 날짜 기록은 08에서 제거했다. 기록·필름·설정 하단 탭과 저장되는 라이트 모드 토글을 추가했다. 필름 탭에서는 빈티지·흑백·온기·청명·바램·내추럴 6종의 필름통과 커피 예시의 원본 비교를 제공한다. 촬영 필름 목록은 가로 스크롤로 선택한다. 기록 화면은 달력으로 고정하며 월 이동과 기록 상세 열기를 제공한다. 검증 결과와 실기기 확인 항목은 [TASKS.md](docs/TASKS.md)에 정리한다.

Xcode에서 `iosApp/Damharu.xcodeproj` → `Damharu` scheme → iPhone 시뮬레이터로 실행한다. 개발 환경과 코드 구조는 [DEVELOPMENT.md](docs/DEVELOPMENT.md)에 정리했다.

- 서버·로그인 없이 기기에 기록 저장
- 하루 한 장, 글은 선택. 기록은 오늘만, 사진은 앱의 카메라로만. 찍기 전에 필름을 끼우고, 필름이 적용된 한 장만 남긴다
- iOS와 Android에서 공통 Kotlin/Compose 화면 사용
- 디자인: 기본 다크, 설정에서 아이보리 라이트 모드 선택. 순흑 배경, 명조 헤드라인, 모노 메타데이터, 번트 오렌지 포인트의 빈티지 카메라 무드

## 시작하기
