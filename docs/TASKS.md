## 2026-09-20: 커스텀 촬영 화면 시안

- 시안 제공: 큰 미리보기 아래 0.5 / 1× / 2 배율, 중앙 촬영 버튼과 오른쪽 필터 버튼으로 구성. 어두운 바탕에 올리브 포인트, 크림색 비교 옵션 제공.
- 필터 버튼을 누르면 원본/온기/맑음/필름/흑백 선택을 미리보기 하단에 임시 노출하는 제안. 구도는 일러스트, 줌과 필터는 시안용 표현이다.
- 앱 코드와 확정 제품 명세는 변경하지 않음. 시안 마크업 확인만 진행했으며 브라우저 렌더링, 앱 빌드, 실제 촬영 검증은 수행하지 않음.
- 다음 작업: 사용자 디자인 검토 후 iOS 커스텀 카메라 범위 확정. 실제 지원 렌즈에 맞춘 배율, 촬영 종료 동선과 필터 적용 시점 결정.

### 촬영 시안 2차 — 추가 참고 반영

- 첨부된 약 22초 영상의 주요 프레임을 확인. 연속 배율 변화, 중앙 포인터와 이동 눈금, 배율·초점거리 표시를 시안에 반영했다.
- 0.5–6배 범위와 24mm 기준 환산은 참고 영상에 맞춘 시안용 값이며 실제 기기 지원 명세가 아니다.
- 오른쪽 필터는 노란색 소형 카메라 형태로 변경. 영상에서 필터 패널 열림은 확인되지 않아 기존 5개 필터 선택 제안을 유지했다.
- 시안 파일 소스 확인 완료. 브라우저 렌더링 및 실제 카메라 검증은 미실행. 다음 작업은 2차 시안 검토 후 iOS 구현 범위 확정.

## 2026-09-20: 승인된 커스텀 촬영 화면 적용

- 시스템 촬영 화면을 공통 CMP `CameraScreen`으로 교체. 중앙 포인터·이동 눈금의 연속 줌, 중앙 셔터, 오른쪽 노란 카메라 모양 필터 버튼, 상단 닫기 구현.
- iOS AVFoundation과 Android CameraX 1.5.3 연결. 기기 지원 줌 범위를 사용하며 최대 6배로 제한. 지원하지 않는 초광각과 근거 없는 24mm 환산 표시는 하지 않는다.
- 원본/온기/맑음/필름/흑백을 촬영 전에 미리보고 선택. 필터 없는 사진을 기존 임시 이미지 정규화·사진 확정·저장 흐름으로 전달하며 필터 선택도 유지한다. 촬영만으로 저장 완료 처리하지 않는다.
- 권한 거부/카메라 불가/중단 오류 안내, 앱 백그라운드에서 세션 중단, 닫을 때 세션 및 관찰자 정리, 중복 촬영 방지. Android의 촬영 화면은 밝은 상태바 아이콘 사용.
- 학습: 공유 UI는 `CameraState`와 `CameraActions`만 알고, AVFoundation/CameraX가 실제 카메라를 제어한다. 필터 행렬을 미리보기와 기존 저장 경로에서 재사용해 원본을 보존한다.

- 상세: 모노 메타 라인, 명조 날짜, 메모 또는 "오늘을 한 줄로 남겨보세요"(탭하면 편집), 헤어라인 아래 이전/다음 날짜 링크, 사진에는 표시 전용 입자·비네팅.
