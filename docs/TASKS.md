## 작업 종료 기록

- 2026-09-17: 프로젝트 폴더, 기획 문서, 작업 규칙, 홈 작업 범위 생성. 기존 시안 두 개 보관. 앱 코드 및 빌드 검증은 아직 없음.
- 2026-09-17, 01 완료: Kotlin 2.4.10 / CMP 1.11.1 / Gradle 8.14 프로젝트 생성. commonMain의 테마·날짜 모델·홈 화면을 SwiftUI 진입점에 연결. 월 이동, 이번 달 복귀, 미래 날짜 비활성화, 오늘 강조, 첫 사용·샘플·오늘 완료 상태 구현. 사진 추가/상세는 HomeAction 콜백과 준비 중 안내까지만 구현.
- 검증: `:shared:iosSimulatorArm64Test` 5개 통과(윤년·세기 규칙, 28/29/30/31일, 일요일 시작, 6주 월, 연도 경계, 1999–2030년 전체 월, 행동 구분). `xcodebuild build-for-testing` 및 `test-without-building` 성공, UI 테스트 2개 통과(월 이동, 미래 비활성화, CTA 가시성, 기록/추가 분기).
- 시각 확인: iPhone 17e / iOS 26.4, 390pt 너비에서 홈 샘플 화면 겹침·잘림 없음. `docs/screenshots/home-sample.png` 보관. 긴 화면은 세로 스크롤 지원. 320pt와 실기기는 아직 검증하지 않음.
- 환경: JBR 21은 Android Studio 번들 사용. Xcode 26.6에서 실제 빌드 통과. Gradle 8.14의 향후 지원 종료 경고와 Skia ICU 데이터 오브젝트의 iOS simulator 18.5 링크 경고가 남음. iOS 16 런타임은 미검증. 전역 경고 숨김 설정은 추가하지 않음.
- 학습: commonMain은 플랫폼 API에 의존하지 않고 UI/상태를 공유한다. iosMain은 UIViewController 연결을 담당한다. HomeScreen은 상태 입력과 콜백 출력만 갖고 App이 상태를 소유한다. 실제 사진·영구 저장은 다음 단계.
