## 작업 종료 기록

- 2026-09-17: 프로젝트 폴더, 기획 문서, 작업 규칙, 홈 작업 범위 생성. 기존 시안 두 개 보관. 앱 코드 및 빌드 검증은 아직 없음.
- 2026-09-17, 01 완료: Kotlin 2.4.10 / CMP 1.11.1 / Gradle 8.14 프로젝트 생성. commonMain의 테마·날짜 모델·홈 화면을 SwiftUI 진입점에 연결. 월 이동, 이번 달 복귀, 미래 날짜 비활성화, 오늘 강조, 첫 사용·샘플·오늘 완료 상태 구현. 사진 추가/상세는 HomeAction 콜백과 준비 중 안내까지만 구현.
- 검증: `:shared:iosSimulatorArm64Test` 5개 통과(윤년·세기 규칙, 28/29/30/31일, 일요일 시작, 6주 월, 연도 경계, 1999–2030년 전체 월, 행동 구분). `xcodebuild build-for-testing` 및 `test-without-building` 성공, UI 테스트 2개 통과(월 이동, 미래 비활성화, CTA 가시성, 기록/추가 분기).
- 시각 확인: iPhone 17e / iOS 26.4, 390pt 너비에서 홈 샘플 화면 겹침·잘림 없음. `docs/screenshots/home-sample.png` 보관. 긴 화면은 세로 스크롤 지원. 320pt와 실기기는 아직 검증하지 않음.
- 환경: JBR 21은 Android Studio 번들 사용. Xcode 26.6에서 실제 빌드 통과. Gradle 8.14의 향후 지원 종료 경고와 Skia ICU 데이터 오브젝트의 iOS simulator 18.5 링크 경고가 남음. iOS 16 런타임은 미검증. 전역 경고 숨김 설정은 추가하지 않음.
- 학습: commonMain은 플랫폼 API에 의존하지 않고 UI/상태를 공유한다. iosMain은 UIViewController 연결을 담당한다. HomeScreen은 상태 입력과 콜백 출력만 갖고 App이 상태를 소유한다. 실제 사진·영구 저장은 다음 단계.

## 2026-09-18: 02–07 구현 및 검증

- iOS PHPicker와 UIImagePickerController, Android Photo Picker와 외부 카메라 TakePicture/FileProvider 연결. 취소/선택 실패/카메라 불가/권한 거부 안내, 날짜 선택, 임시 파일 정리.
- 공통 사진 편집: 원본/온기/맑음/필름/흑백, 강도, 원본 비교, 하단 고정 저장 버튼. 사진 디코딩 및 출력은 백그라운드 작업.
- JSON 목록과 이미지 파일로 로컬 저장. 이미지가 준비된 후 목록을 원자적으로 교체하며 저장 실패 시 기존 기록을 유지. 원본 사본/최종 JPEG/달력 썸네일 관리.
- 상세의 큰 사진, 선택적 120자 메모, 사진 변경과 같은 날짜 교체 확인, 삭제 확인, 이전/다음 및 스와이프 탐색. 메모 편집 모드에서는 사진을 접어 키보드 공간 확보.
- Android 실행 모듈 추가. AGP 9.1.0에 맞춰 Gradle 9.3.1로 갱신.

### 자동 검증 결과

- iOS simulator 공통 테스트 12개 + Skia 이미지 출력 픽셀 테스트 1개: **13개 통과**.
- Android host 공통 테스트: **12개 통과**.
- iPhone 17e / iOS 26.4, Xcode 26.6: 앱 빌드와 UI 테스트 **2개 통과**. 달력 이동/미래 비활성화/촬영 불가, 시스템 선택기 취소·실제 보관함 사진 선택, 필터 저장, 앱 종료·재실행 복원, 메모 저장, 삭제 후 재실행 검증. 사진 교체 확인 경로도 기존 테스트 기록을 교체하는 재실행에서 통과.
- Pixel 10 Pro / Android 17 에뮬레이터: APK 빌드 및 instrumentation **2개 통과**. 시스템 선택·필터·저장·Activity 재생성·메모·삭제, Bitmap 출력 픽셀 검사.
- Android `lintDebug`: 오류 없음. 최신 SDK/라이브러리 권장, 런처 아이콘 및 OS 백업 정책 등 경고는 출시 정리 항목으로 남김.
- 공통 저장소 테스트는 정상 저장/재로드/교체/메모/삭제뿐 아니라 렌더 실패·디스크 쓰기 실패·정리 실패·손상된 목록·경로 탈출을 검사.
- 필터 픽셀 테스트는 5가지 필터의 70% 강도를 양 플랫폼의 실제 JPEG 출력과 비교. JPEG 반올림 허용 오차 4/255 내 통과.
- `docs/screenshots/photo-editor.png`, `photo-detail.png`: 시뮬레이터 기본 사진으로 확인한 실제 화면. 기존 home-sample.png는 01 단계의 일러스트 미리보기이며 현재 실기록 화면이 아님.

### 남은 기기 확인

- iOS/Android 실제 카메라 촬영, 카메라 권한 거부 후 설정 복귀, 카메라 앱 부재/촬영 앱 중단.
- iCloud/원격 사진 다운로드 실패, 저용량 디스크의 실제 OS 오류, 대용량/광색역/회전·미러링 사진 실물 비교.
- iOS 16 및 Android API 26, 320pt/큰 글자, VoiceOver/TalkBack 전체 탐색.
- Android 프로세스 강제 종료 후 저장 기록 복원(자동 테스트는 Activity 재생성 및 저장소 재로드를 검사). 저장 전 사진 선택 중 프로세스가 종료되면 다시 선택하도록 설계.
- 앱 아이콘/배포 서명/스토어 제출은 이번 범위에 포함하지 않음.
