# 필름 확장 검토 — 2026-11-09

상태: 2026-11-09 사용자 적용 요청에 따라 신규 4종을 앱 코드에 반영. 아래 우선순위·단계는 당시 제안 기록이며 실제 반영은 온기·청명·바램·내추럴 4종 모두 진행했다. 최신 검증 결과는 docs/TASKS.md 참고.

## 권장안

**온기·청명 2종을 우선 추가하여 2종 → 4종으로 확장한다.** 바램·내추럴은 후속 후보로 남긴다. 모든 후보를 한 번에 추가하는 안도 비교 자료에 포함하되 초기 선택 부담과 촬영 목록 변경 비용을 고려해 단계적 확장을 권장한다. 이는 제품 설계 판단이며 사용자 조사로 검증된 결론은 아니다.

| 후보 | 차별점 | 주요 장면 | 우선순위·주의점 |
|---|---|---|---|
| 온기 / WARM / `warm` | 색을 따뜻하게, 약한 입자와 비네팅 | 카페·음식·오후 실내 | 1차. 전구 아래 피부·흰 벽의 노란 착색 확인 |
| 청명 / CLEAR / `clear` | 약한 청색 균형과 대비, 질감 없음 | 하늘·바다·밝은 산책길 | 1차. 차가운 피부와 밝은 영역 클리핑 확인 |
| 바램 / FADE / `fade` | 들뜬 검정·낮은 채도·작은 입자, 비네팅 없음 | 흐린 날·오래된 공간·사물 | 후속. 저조도에서 장면이 흐려지는지 확인 |
| 내추럴 / NATURAL / `natural` | 미세한 온기·채도 절제, 질감 없음 | 창가 인물·일상 | 후속. 필름 없음·온기와 구분이 충분한지 확인 |

이름·id·효과 수치는 모두 제안이다. 이전 `iphone_x` 기획은 구현되지 않았고 이번 내추럴은 그 분위기를 일반 이름으로 재해석한 대안이다. 특정 iPhone 센서·HDR·색 처리의 재현을 주장하지 않는다. 기존 기획의 자동 채택·폐기를 의미하지 않는다.

## 확인한 현재 상태

- `Film.available`: 필름 없음·빈티지·흑백. 테스트 필름은 과거 기록 해석용이다.
- 빈티지: 색상 행렬 없음, 비네팅 .42 / 반경 .72 / 입자 .30. 따뜻한 색을 만드는 필름은 아니다.
- 흑백: 공통 RGB 행렬, 비네팅 .28 / 반경 .72 / 입자 .23.
- 카메라: 현재 목록 뒤 준비중 2칸을 고정 추가. 온기·청명을 넣을 때 준비중도 함께 제거해야 기존 5칸을 유지한다.
- 진열장: 2열, 빈티지와 그 외(흑백) 분기로 제목·사진·설명을 결정한다. 새 필름별 매핑이 필요하다. 준비중 카드는 별도 1개다.
- 현재 최신 리소스는 필름통이다. 이전 아이폰 X 제안의 카메라 아이콘 방향을 그대로 따르지 않는다.

## 검토 자료

- `design/film-expansion/review.html`: 외부 리소스 없이 열리는 비교 자료. 앱의 커피 예시를 내장하고 원본/선택 효과와 전체 라인업을 비교한다. 내 사진 선택은 브라우저 안에서만 처리한다.
- `design/film-expansion/films.json`: 동일한 필름 정의. 실제 필름 6종과 필름 없음 기준 1개, 총 7개 항목이다.
- 기존 근거: `design/film-study/README.md`, `docs/proposals/iphone-x-film.md`, `docs/tasks/09-camera-film.md`, `docs/tasks/12-film-shelf.md`, 현재 공통 코드.

커피 예시는 사진의 중립성이 검증되지 않았고 야외·인물 판단에는 부족하다. 원본 비교는 필름 효과 전 입력이라는 뜻이다. 브라우저 행렬은 동일 수치로 계산하지만 입자의 난수·크기·색공간·비네팅은 네이티브와 픽셀 단위로 일치하지 않는다. 기존 질감의 alpha 값은 입자 불투명도의 상한 계수이며 grain 값 자체를 픽셀 밝기 변화율로 읽지 않는다.

온기·청명·바램은 이전 비교안에서 출발했고, 질감은 서로 구분되도록 조정했다. 내추럴은 채도 약 96%·대비 약 1.02·미세한 채널 차이를 노린 새 시제품이다. 후보의 모든 행렬은 `films.json`에 명시하며 실측값은 아니다. RGBA 4×5 행렬의 RGB 오프셋은 0–255 단위다. 톤 커브·선택 색상·HDR 역처리는 행렬로 구현하지 않는다.

## 채택 후 구현 순서

1. 피부·흰 벽, 전구 아래 음식, 하늘·초록, 역광, 검은 옷, 저조도 6개 장면을 같은 입력으로 비교해 고정 강도를 조정한다. 여러 피부 톤을 포함한다.
2. commonMain의 필름 정의에 행렬·질감·id를 추가하고 카메라·진열장·예시 설명·아이콘을 필름별로 매핑한다. 별도 모듈이나 저장 스키마를 추가할 필요는 없다.
3. 1차는 준비중 2칸을 교체해 카메라 5칸 유지, 진열장 실제 4종을 2열 표시하고 준비중 카드는 제거하는 안을 제안한다. 4종 모두 추가한다면 촬영 선택지는 7개이므로 가로 스크롤과 선택 항목 노출·접근성을 별도 설계한다.
4. iOS 개발 비교 경로에서 먼저 검증한다. 공통 available 변경은 Android에도 즉시 노출될 수 있으므로 iOS 검증 전 정식 목록에 등록하지 않는다. 플랫폼 OS API는 기존 플랫폼 구현에 둔다.
5. 프리뷰·촬영 비행·저장본의 색 일관성과 효과 단일 적용을 검증한다. 썸네일·상세는 처리된 사진을 그대로 사용한다. 시간 각인은 효과 뒤 오렌지로 유지한다.
6. 신규 id 저장·재로드, 기존 `test`·`vintage`·`monochrome`과 미지 id 복원, 회전·줌·저조도, 작은 화면·VoiceOver, 지연을 확인한다. iOS 이후 Android를 검증한다. 저장된 과거 사진을 다시 처리하지 않는다.

필름 색을 commonMain에서 정의하는 이유는 “색의 규칙”을 한 곳에서 관리하기 위해서다. 프리뷰와 저장은 서로 다른 렌더러가 그리므로 같은 수치를 전달하더라도 실제 출력 검증이 필요하다.

하루 한 장·오늘만 촬영·촬영 전 선택·고정 강도를 유지한다. 검토 도구의 파일 선택과 원본 비교를 앱 기능으로 추가하지 않는다. 2026-11-09: 필름통 신규 에셋 4종을 `design/film-expansion/icons/`에 제작하고 비교 자료에 추가했다. PNG 규격·투명도와 이름·형태를 확인했다. 앱 리소스 반영·실제 축소 가독성 검증은 후속 작업이다.
