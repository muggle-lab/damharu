# 첫 주 브리프와 대표 검토함

작성: 2026-11-09. 미발행. 공개 계정 조사 전이므로 아래 타깃과 메시지는 제품 문서 기반 가설이다.

## 팀장 브리프

목표: 기록 부담·사용 경험·평범한 순간의 세 메시지로 Threads 게시물 3건을 준비한다. 기존 계정 말투와 지표를 확인한 후 발행일을 정한다. 성과 목표 숫자는 기준 수치 확보 전 미설정이다.

독자 가설: 긴 일기를 부담스러워하지만 사진으로 하루를 기억하고 싶은 사람. 앱의 기능을 나열하기보다 기록을 시작할 이유와 실제 흐름을 보여준다.

## T01 — 기록 부담

목적: 담하루의 가치를 소개한다. 텍스트 단독 발행 가능한 초안이다.

첫 문장 A: 일기를 길게 쓰기엔 조금 지친 날.
첫 문장 B: 오늘을 기억하고 싶은데, 무슨 말을 써야 할지 모르겠다면.

본문(A 선택):

> 일기를 길게 쓰기엔 조금 지친 날.
>
> 사진 한 장으로 오늘을 남겨보면 어떨까요.
>
> 담하루 - 오늘 하루의 기록.
> 사진 한 장이면, 오늘의 기록은 끝.
>
> https://apps.apple.com/kr/app/id6826126219

행동 유도: 스토어에서 앱 확인.
사진: 필수 아님. 출시 앱 화면 확보 시 첨부 가능.
근거: 사용자가 확인한 이름·출시 여부, 제품 핵심 문구.
검수: 문체 확인 완료. 스토어 링크의 실제 기기 열림과 계정 말투 확인 대기. 무료·평점·필름 종류 등 미확인 주장은 없음.
대표 결정: 문구 선택·발행 여부 미확정.

## T02 — 실제 사용 흐름

목적: 사진이 기록으로 남는 과정을 보여준다.

첫 문장 A: 오늘을 남기는 데, 긴 문장은 필요 없어요.
첫 문장 B: 사진을 찍고, 오늘의 기록을 남겨요.

본문(A 선택):

> 오늘을 남기는 데, 긴 문장은 필요 없어요.
>
> 담하루에서 사진을 찍고,
> 달력에 남은 오늘을 확인해보세요.
>
> 사진 한 장이면, 오늘의 기록은 끝.

행동 유도: 영상에서 기록 흐름 확인. 링크는 계정 소개 확인 후 결정.
촬영 목록: App Store 출시 버전 실행 → 카메라 진입 → 주변 사물 촬영 → 저장 후 달력 확인. 화면에 타인의 사진이나 개인정보가 없는지 확인한다. 길이는 실제 촬영 후 편집하며 저장 시간을 왜곡하지 않는다.
근거: 제품 문서의 촬영·달력 흐름. 출시 버전 일치 미확인.
검수: 자료 대기. 개발 빌드 캡처를 출시 앱 화면으로 대체하지 않는다. 실제 영상 없이 영상 제작 완료로 표시하지 않는다.
대표 결정: 출시 앱 녹화 확보 후 검토.

## T03 — 평범한 하루

목적: 독자가 남기고 싶은 장면에 대한 구체적인 답변을 얻는다. 텍스트 단독 초안.

첫 문장 A: 오늘을 한 장으로 남긴다면, 무엇을 찍고 싶나요.
첫 문장 B: 오늘 다시 보고 싶은 장면이 있나요.

본문(A 선택):

> 오늘을 한 장으로 남긴다면, 무엇을 찍고 싶나요.
>
> 식어가는 커피.
> 집으로 돌아가는 길.
> 창가에 잠깐 머문 빛.
>
> 특별하지 않은 장면도 오늘의 기록이 될 수 있어요.

행동 유도: 남기고 싶은 장면을 답글로 이야기하기.
사진: 필수 아님. 추가 시 직접 촬영했거나 사용권이 확인된 한 장.
검수: 제품 기능 주장·허구의 후기 없음. 텍스트 검수 완료, 계정 말투 확인 대기.
대표 결정: 발행 여부 미확정.

## 리서치 인계

현재 외부 반응이나 경쟁 서비스 조사 결과는 없다. 계정 주소를 받으면 소개·공개 최근 게시물에서 확인 가능한 말투와 주제를 살피고 출처·확인일을 기록한다. 비공개 지표는 사용자 제공 시에만 사용한다.

## 대표에게 필요한 입력

1. Threads 계정 주소.
2. T01·T03 문구 수정 의견 또는 발행 희망 여부.
3. T02 제작에 사용할 출시 앱 화면 녹화의 확보 가능 여부.

계정 주소가 없어도 초안 보관과 작업 정리는 진행할 수 있다. 발행·성과 측정 완료는 실제 URL과 관찰 자료가 생긴 뒤 기록한다.
