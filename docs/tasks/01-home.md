# 01 — 초기 설정과 홈 달력

## 목표

KMP + CMP 앱을 iOS에서 실행하고, 공통 Compose UI로 홈 달력을 구현한다.

## 범위

- 설치된 JDK, Xcode, 빌드 도구를 확인한다.
- 공식 문서로 Kotlin/Compose/Gradle 버전 호환성을 확인하고 최소 프로젝트를 생성한다.
- iOS 진입점과 commonMain 앱 진입점을 연결한다.
- 담하루 테마, 날짜별 샘플 기록 모델, 홈 달력 UI를 구현한다.
- 월 이동, 오늘 표시, 사진이 있는 날과 없는 날, 첫 사용 상태를 지원한다.
- 날짜/사진 클릭과 오늘 한 장 남기기는 콜백까지 연결한다. 미구현 화면으로 이동한 것처럼 가장하지 않는다.
- 후속 OS 기능 연결이 가능하도록 구조를 잡되 Android 화면/API 구현은 진행하지 않는다.

## 제외

실제 사진 접근, 카메라, 필터 엔진, DB, 메모 편집, 로그인, 서버.

## 검증

- 가능한 iOS 시뮬레이터 빌드/실행. 환경상 불가하면 정확한 원인을 기록한다.
- 28/29/30/31일, 월 시작 요일, 연도 경계에서 날짜 배치 확인.
- 작은 화면에서 겹침과 잘림 확인.
- 변경 요약, 학습 포인트, 다음 작업을 docs/TASKS.md에 기록.
