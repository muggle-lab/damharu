# 03 — 사진 확정·필터

- 공통 CMP 화면에 정규화 사진 미리보기, 원본/온기/맑음/필름/흑백 썸네일을 구현한다.
- 원본이 기본이며 필터 선택 시 강도(0–100%) 및 원본 비교를 제공한다.
- 같은 RGBA 행렬을 Compose 미리보기와 iOS Skia/Android Bitmap 출력에 사용한다.
- 원본 비교는 미리보기에만 적용하며 선택한 필터 설정은 유지한다.
- 닫을 때 미저장 사진 폐기를 확인하고 임시 이미지를 정리한다.
- 실제 JPEG 출력 색상은 플랫폼별 픽셀 테스트로 검증한다(JPEG 반올림 허용 오차 4/255).
