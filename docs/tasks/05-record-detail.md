# 05 — 기록 상세

- 날짜, 전체 사진(Fit), 메모가 있을 때만 메모를 표시한다.
- ‘한 줄 남기기/수정’에서만 입력란을 열고 최대 120자로 저장한다.
- 좌우 스와이프와 이전/다음 버튼으로 기록 날짜를 탐색한다.
- 사진 변경은 선택·필터 화면을 재사용하고 저장 시 교체 확인을 받는다.
- 삭제 전 사진과 메모 삭제를 확인한다. 취소하면 기존 기록을 유지한다.
- 메모 수정 중 닫기는 변경 폐기를 확인한다.

## 2026-09-21 — 스토리보드 기준 변경

- 구성: 큰 사진 → 모노 메타 라인(날짜·요일) → 명조 날짜 "9월 20일, 일요일" → 메모 → 헤어라인 아래 "‹ 09.19 / 다음 ›".
- 메모가 없으면 "오늘을 한 줄로 남겨보세요" 플레이스홀더를 보여 준다(기존 "메모가 있을 때만 표시"에서 변경).
- 사진 변경은 오늘 기록에서만 노출: 교체 확인 → 카메라 재촬영 → 바로 교체 저장. 선택·필터 화면 재사용은 폐기.
- 지난 기록 삭제 확인창에 그 날짜를 다시 채울 수 없음을 명시한다.
- 문서만 갱신. 코드 반영은 08-storyboard-alignment.md에서 진행한다.
