# 12 — 필름 진열장

- 2026-10-30 선택된 2번 카메라 진열장을 실제 필름 탭으로 구현.
- 하단 탭 순서: 기록 / 필름 / 설정. iOS는 SwiftUI TabView, Android는 기존 Material NavigationBar에 필름 항목 추가.
- 제목은 `필름 진열장`. 빈티지·흑백 필름통을 2열로 배치하고 이름·짧은 설명·예시 보기 제공.
- 필름 없음 행, 그 아래 구분선과 감성 문구는 제외.
- 필름을 누르면 모달 바텀시트에서 커피 예시와 원본을 전환. 실제 Film 색상 행렬과 공통 입자·비네팅 효과를 재사용.
- 미리보기 선택은 촬영 필름 설정이나 저장된 기록을 변경하지 않는다.
- 공통 화면: `FilmShelfScreen.kt`. 제작 필름통 PNG와 커피 샘플을 Compose Resources에 포함.
- 검증 결과와 남은 확인은 docs/TASKS.md 참고.

- 후속 변경: 마지막에 `필름 준비중` 카드 하나 추가. 2열 기준 다음 줄 왼쪽에 배치하며 물음표·COMING SOON·곧 만나요 표시. 탭 동작 없이 비활성 접근성 상태로 제공.

- 준비중 항목도 무지 필름통(film_cartridge_none)으로 통일. 55% 불투명도로 표시하며 비활성·클릭 불가 상태 유지.

## 2026-11-09 — 신규 필름 4종 적용

- 온기·청명·바램·내추럴을 기존 빈티지·흑백에 추가. `Film.kt`에 검토안의 4×5 행렬·질감을 고정 강도로 정의. 저장 id는 `warm` / `clear` / `fade` / `natural`.
- 카메라: 준비중 제거, 필름 없음 포함 7개 선택지를 72dp 타일 가로 스크롤로 표시. 목록 재열기 시 선택 필름 노출. 셔터 위치 유지.
- 진열장: 2열·3행으로 6종 표시, 준비중 카드 제거. 이름·설명·이미지를 필름별로 매핑하고 커피 예시 원본 비교에 같은 효과 적용.
- 공통 리소스: 생성 원본은 보관하고 앱 PNG는 512×512 RGBA로 축소. 카메라·진열장이 동일한 매핑 사용.
- 검증 결과와 실기기 확인 항목: TASKS.md의 신규 필름 적용 항목 참고.
