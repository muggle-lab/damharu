## 확정 범위

- 2026-10-26 사용자가 3개 시안 중 갤러리·타임라인 채택. 한 장 앨범은 제외.
- 월 이동 줄 맨 오른쪽의 현재 모드 이름·아래 화살표를 누르면 모달 바텀시트에 달력 / 갤러리 / 타임라인 표시. 선택 시 닫히며 전환하고 현재 선택에 체크 표시. 닫기·배경 탭·손잡이 아래 드래그로 취소. 선택 월은 공유, 마지막 모드는 UserDefaults / SharedPreferences에 저장.
- 갤러리는 해당 월 기록만 최신순 3열 3:4로 표시. 타임라인은 최신순 날짜·사진·실제 메모·필름 이름. 없는 메모는 생략.
- 사진은 기존 상세로 연결. 메모·삭제 변경 즉시 반영. 오늘만 촬영, 현재 모드로 저장 후 복귀. 사진 비행은 해당 모드의 오늘 사진으로 착지.
- 빈 월·초기 데이터 로딩을 구분. 실데이터를 사용하며 시안 예시 문구·사진을 앱에 넣지 않음.
- 스크롤 상태는 App에 두어 상세·설정 왕복 시 유지. 월 이동·TODAY는 맨 위로. 촬영은 오늘 항목을 노출.

## 핵심 개념

보기 모드는 저장 모델이 아니라 표현 상태다. 공통 DiaryEntry에 기존 메모·필름·사진 경로를 전달하고 동일 목록을 필터·정렬한 뒤 LazyColumn으로 필요한 항목만 구성한다. OS별 설정 저장만 호스트가 담당하며 새 라이브러리·저장 형식 변경은 없다.

## 모드 선택 바텀시트

HomeViewModeSheet는 commonMain의 Dialog 창 위에 스크림과 아래 정렬 패널을 배치하고 진입·퇴장 이동을 애니메이션으로 처리한다. 홈 위에 단순히 겹치는 방식과 달리 네이티브 하단 탭까지 모달 범위에 포함한다. 플랫폼별 DialogProperties만 expect/actual로 분리해 iOS 플랫폼 인셋·기본 스크림·기본 애니메이션을 끄고 Android는 화면 가장자리까지 확장한다. 시트가 하단 안전 영역 패딩과 배경을 직접 소유한다. 기존 설정 저장·기록 목록에는 변경이 없다.
