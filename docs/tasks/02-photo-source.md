# 02 — iOS 사진 선택·촬영

## 먼저 읽기

AGENTS.md, docs/PRODUCT.md, docs/TASKS.md, docs/DEVELOPMENT.md.

## 시작 지점

`App.kt`의 `HomeAction.AddRecord(date)`는 현재 안내만 표시한다. 이를 사진 선택/촬영 진입으로 연결한다. `OpenRecord`의 실제 상세 구현은 아직 하지 않는다.

## 범위

- 공통 사진 입력 인터페이스와 iOS 시스템 사진 선택기·촬영 연동.
- 진입 날짜를 유지하고 과거 날짜 기록 지원.
- 선택/촬영 결과를 앱이 관리할 임시 이미지로 전달하고 간단한 미리보기 제공.
- 취소, 접근 거부, 촬영 불가(시뮬레이터 포함), 이미지 읽기 실패 처리.
- 원본 방향과 임시 파일 수명 관리. 사용자 사진을 삭제하거나 원본을 변경하지 않음.
- 다음 필터 화면으로 전달할 데이터 경계까지만 구현. 필터 엔진·DB·영구 저장 제외.
- 사용자에게 저장 완료로 잘못 표시하지 않음. 개발 샘플과 실제 이미지 구분 유지.

## 검증 및 마무리

iOS 빌드와 가능한 선택/취소 동작을 검증한다. 카메라 실기기 검증이 불가능하면 명시한다. 변경한 동작에 필요한 테스트만 수행하고 TASKS.md를 갱신한다. Android 구현은 이후 단계다.
