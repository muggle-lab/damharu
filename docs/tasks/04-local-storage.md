# 04 — 로컬 저장

- 날짜별 한 기록. 서버/계정 없이 앱 내부 디렉터리에 JSON 목록과 JPEG 파일을 저장한다.
- 기록: 날짜, 필터 없는 가져온 이미지, 필터 결과, 달력용 썸네일, 필터 종류/강도, 선택 메모.
- 새 이미지들을 먼저 쓴 뒤 목록을 원자적으로 교체한다. 실패 시 기존 기록을 유지한다.
- 같은 날짜 교체를 확인하며 해당 날짜의 메모를 유지한다.
- 목록 커밋 뒤 참조되지 않는 이미지를 정리한다. 목록 읽기 실패를 빈 기록으로 처리하지 않는다.
- 저장/교체/삭제/재로드, 렌더 실패, 목록 쓰기 실패, 정리 실패, 잘못된 경로를 테스트한다.

이미지 정책: 긴 변 최대 2048px, 방향 정규화, JPEG, 투명 영역은 흰색. ‘원본’ 파일은 필터 없는 앱용 사본이다. 사용자의 사진 보관함 원본 파일은 변경하지 않는다. GPS 등 사진 메타데이터는 저장하지 않는다. 썸네일은 긴 변 180px. 클라우드 동기화 및 백업/내보내기는 범위 밖이다.
