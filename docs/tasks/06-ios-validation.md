# 06 — iOS 통합 검증

자동화 대상:
- 달력 월 이동, 미래 날짜 비활성화, 시뮬레이터 촬영 불가 안내.
- 시스템 PHPicker 열기/취소/재선택, 실제 시뮬레이터 보관함 사진 가져오기.
- 필터 선택, 저장, 앱 종료/재실행 후 복원, 메모 저장, 삭제 후 재실행.
- Skia JPEG 출력과 공통 필터 행렬의 픽셀 일치 및 리사이즈.

실행 결과는 `docs/TASKS.md`에 기록한다. 카메라 실제 촬영, 권한 거부 후 설정 복귀, iCloud에서 다운로드가 필요한 이미지, iOS 16 실기기 동작은 실제 환경에서 별도 확인한다. 시뮬레이터 결과를 실기기 검증으로 표시하지 않는다.

## 2026-09-21 — 스토리보드 기준 변경

- PHPicker 열기/취소/보관함 가져오기, 필터 선택, Skia 필터 행렬 픽셀 일치 항목은 08 반영 후 자동화 대상에서 제거한다.
- 추가 대상: 촬영 버튼 → 카메라 → 촬영 즉시 저장 → 홈 썸네일, 닫기 시 무변경, 지나간 빈 날짜 탭 무반응, 지난 기록에서 사진 변경 미노출, 재실행 후 복원.
- 시뮬레이터는 Debug 전용 `--camera-preview` 입력을 계속 사용하며 실제 카메라 센서 검증으로 표시하지 않는다.
