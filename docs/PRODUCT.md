# 제품 및 디자인 결정

> 2026-09-21: 스토리보드(`storyboard` 워크트리의 `index.html`) 기준으로 전면 갱신. 앱 코드는 아직 이전 명세(사진 선택기·필터·과거 날짜 기록) 상태이며, 코드와의 차이와 작업 목록은 docs/tasks/08-storyboard-alignment.md 참고.

## 확정 사항

- 이름: 담하루
- 스토어 이름 후보: 담하루 — 하루 한 장 사진 일기
- 핵심 문구: 사진 한 장이면, 오늘의 기록은 끝.
- 대상: 일기나 브이로그는 부담스럽지만 사진 한 장으로 하루를 남기고 싶은 사람
- 개인 기록 전용. 서버·계정·로그인 없이 로컬 저장
- KMP + CMP 학습과 실제 앱 개발을 병행
- iOS 구현 후 Android 구현
- **하루 한 장**: 날짜당 기록 1건. 달력 셀 하나에 사진 하나
- **오늘만 기록**: 기록 생성·교체는 오늘 날짜만 가능. 지나간 빈 날짜는 다시 채울 수 없음
- **앱 내 촬영만**: 모든 사진은 담하루의 커스텀 카메라로 찍는다. 갤러리·외부 사진 가져오기 없음
- **필터·편집 없음**: 촬영 즉시 저장. 사진 확정/필터 화면 없음

## 기록 흐름

홈 달력 → 커스텀 카메라 → 촬영 즉시 저장 → 홈 달력

선택 화면이나 확인 단계 없이 셔터 한 번으로 오늘의 기록이 끝난다. 저장 후 메모 입력을 요구하지 않는다. 기록한 날짜를 누르면 상세 화면에서 사진을 크게 보고 선택적으로 한 줄을 남긴다.

## 화면

### 01 홈 달력

- 브랜드 캡션 "담 하 루", 헤드라인 "9월, 담아둔 하루"(월마다 숫자만 교체), 보조 문장 "지나간 날들이 여기 모여 있어요."
- 월 내비게이션 ◂ 2026.09 ▸. 기록 수·달성률 카운터는 두지 않음
- 7열 그리드, 요일 헤더 없음, 셀 간격 2px의 밀착인화 느낌. 셀에는 썸네일과 날짜 숫자만 표시하며 사진 개수 표시는 없음
- 오늘: 점선 테두리 + 오렌지 점, 그리드 아래 "● TODAY" 범례. 기록을 새로 만들 수 있는 유일한 날짜
- 지나간 빈 날짜: 더 어두운 비활성 셀. 실패/경고 문구나 연속 기록(스트릭) 압박은 두지 않음
- 미래 날짜: 비활성
- 우하단 금속 질감 촬영 버튼 → 선택 화면 없이 바로 커스텀 카메라
- 탭 동작: 사진 있는 날짜 → 기록 상세 / 오늘(기록 없음) → 카메라 / 오늘(기록 있음) → 기록 상세
- 그리드 아래 하단 섹션은 비워 둠(콘텐츠 미정)

### 02 커스텀 카메라

- 공통 CMP `CameraScreen` + iOS AVFoundation / Android CameraX
- 좌상단 닫기, 3:4 프리뷰(주변은 순흑), 네 모서리 오렌지 브래킷과 중앙 초점 표시
- 줌 눈금 다이얼: 현재 배율 + 0.1× 눈금, 고정된 오렌지 바늘. 핀치 또는 다이얼 좌우 드래그로 연속 줌
- 기기 지원 범위 안에서 0.5×–6×. 지원하지 않는 초광각은 노출하지 않으며 고정 mm 환산 표시는 하지 않음
- 하단 중앙 금속 셔터만 둔다. 필터 버튼·갤러리 버튼 없음
- 촬영 성공 → 바로 저장 후 홈 복귀. 닫기 → 저장 없이 복귀하며 기존 기록을 변경하지 않음
- 카메라 권한 거부 → 안내창으로 설정에서 권한을 켜도록 안내(대체 입력 경로 없음). 촬영 중 에러 → 프리뷰 자리에 안내
- 진입 경로: 홈 촬영 버튼, 오늘 날짜 탭(기록 없을 때), 오늘 기록 상세의 사진 변경. 어느 경로든 기록 날짜는 항상 오늘

### 03 기록 상세

- 큰 사진, 모노 메타 라인(날짜·요일), 명조 날짜 "9월 20일, 일요일", 선택적 한 줄 메모(120자)
- 메모가 없으면 "오늘을 한 줄로 남겨보세요" 플레이스홀더. 탭하면 컴팩트 모드로 전환해 키보드 공간 확보
- 사진 변경은 오늘 기록에서만 노출: 교체 확인 → 카메라로 다시 촬영 → 바로 교체 저장. 지난 기록은 메모 편집과 삭제만
- 삭제: 확인 후 영구 삭제. 지난 기록은 삭제하면 그 날짜를 다시 채울 수 없음을 확인창에 명시
- 좌우 스와이프와 하단 "‹ 09.19 / 다음 ›"으로 다른 기록 탐색. 이동할 기록이 없으면 흐리게

## 저장

- `diary/records.json`(날짜·메모) + 날짜당 사진 한 장(긴 변 최대 2048px, 방향 보정)과 썸네일(180px). 구현은 교체를 원자적으로 하기 위해 폴더 대신 `diary/<날짜>-<id>-photo.jpg` / `-thumb.jpg`처럼 새 이름으로 쓰고 목록을 바꾼다
- 필터·편집이 없으므로 photo.jpg가 곧 원본. 별도 original 사본과 필터 종류/강도 필드는 두지 않음
- 이미지 저장 완료 후 목록을 원자적으로 교체. 실패 시 기존 기록 유지, 임시 파일 정리
- GPS 등 EXIF 메타데이터는 저장하지 않음

## 디자인

벤치마크는 「내가 당신을 사랑할 때 보이는 순간들: 빈티지 카메라앱」. 에셋과 문구는 가져오지 않고 무드만 옮긴다.

- 순흑 위의 사진: 배경 #070706(화면 내부는 #000). 면은 색이 아니라 1px 헤어라인으로 나누고 모서리는 2–4px
- 명조 헤드라인: 제목·본문 모두 명조(Noto Serif KR), 굵기 400/600 두 단계. 현재 구현은 플랫폼 기본 Serif라서 Android는 명조, iOS는 한글이 고딕으로 표시된다(iOS에 한글 명조 시스템 글꼴 없음). 서체 번들 전까지의 임시 상태. "9월, 담아둔 하루"처럼 달 + 쉼표 + 명사구
- 모노 메타데이터: 날짜·배율은 자간 넓은 모노 소형 라벨(예: 2026.09.14 MON, 1.5×)
- 포인트색 번트 오렌지 #D98551은 한 화면에 1–2곳만(오늘 점, 줌 바늘, 뷰파인더 브래킷). 기존 노랑 #E5A62F와 올리브 계열 테마를 대체
- 팔레트: BLACK #070706, PANEL #12110F, TAUPE #5B5548, INK #EDE8DD, MUTED #8F897C, ACCENT #D98551, 날짜 각인 #F08A3C
- 카메라의 물성: 코너 브래킷, 눈금 다이얼, 금속 셔터. 아이콘은 얇은 라인, 버튼은 알약형 아웃라인
- 필름의 흔적: 사진 위 미세한 입자와 비네팅
- 문구: 짧은 평서문, 시처럼 한 줄. 느낌표와 이모지는 쓰지 않음
- 사진 중심. 탭바나 메뉴를 불필요하게 늘리지 않음
- 참고 시안: 스토리보드 `index.html`이 기준. design/daily-photo-design.html, design/photo-filter-design.html은 이전 방향의 기록으로만 보관
- 스토리보드 속 사진은 구도 확인용 그라데이션이며 실제 색감이 아님

## 미확정

- 날짜 각인(사진 우하단 '26 9 20): 스토리보드에 제안으로 표시. 채택하면 photo.jpg에 직접 각인되므로 저장 정책에 반영 필요
- 첫 사용(기록 0건) 상태와 오늘 저장 직후 상태의 홈 표현
