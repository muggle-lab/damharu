## 확정 사항

- 이름: 담하루
- 스토어 이름 후보: 담하루 — 하루 한 장 사진 일기
- 핵심 문구: 사진 한 장이면, 오늘의 기록은 끝.
- 대상: 일기나 브이로그는 부담스럽지만 사진 한 장으로 하루를 남기고 싶은 사람
- 개인 기록 전용. 서버·계정·로그인 없이 로컬 저장
- KMP + CMP 학습과 실제 앱 개발을 병행
- iOS 구현 후 Android 구현
- **하루 한 장**: 날짜당 기록 1건. 달력 셀 하나에 사진 하나
- **오늘만 기록**: 기록 생성·교체는 오늘 날짜만 가능. 지나간 빈 날짜는 다시 채울 수 없음
- **앱 내 촬영만**: 모든 사진은 담하루의 커스텀 카메라로 찍는다. 갤러리·외부 사진 가져오기 없음
- **필름, 편집 없음**: 찍기 전에 카메라에서 필름을 끼운다. 촬영 즉시 필름이 적용된 한 장만 저장하며 사진 확정/편집 화면과 강도 조절은 없음. 필름을 끼우지 않으면 찍힌 그대로(원본) 저장한다. 현재 선택 가능한 필름은 빈티지·흑백·온기·청명·바램·내추럴 6종이다. 필름 없음은 별도 기본 선택이며 준비중 칸은 제거했다

## 기록 흐름

홈 달력 → 커스텀 카메라 → 촬영 즉시 저장 → 홈 달력

선택 화면이나 확인 단계 없이 셔터 한 번으로 오늘의 기록이 끝난다. 저장 후 메모 입력을 요구하지 않는다. 기록한 날짜를 누르면 상세 화면에서 사진을 크게 보고 선택적으로 한 줄을 남긴다.

## 화면

### 01 홈 — 달력

- 브랜드 캡션 "담 하 루", 헤드라인 "9월, 담아둔 하루"(월마다 숫자만 교체), 보조 문장 "지나간 날들이 여기 모여 있어요."
- 월 내비게이션 ◂ 2026.09 ▸. 기록 수·달성률 카운터는 두지 않음
- 7열 그리드, 요일 헤더 없음, 셀 간격 2px의 밀착인화 느낌. 셀에는 썸네일과 날짜 숫자만 표시하며 사진 개수 표시는 없음
- 오늘: 점선 테두리 + 오렌지 점. 기록을 새로 만들 수 있는 유일한 날짜
- 지나간 빈 날짜: 더 어두운 비활성 셀. 실패/경고 문구나 연속 기록(스트릭) 압박은 두지 않음
- 미래 날짜: 비활성
- 하단 플로팅 촬영 그룹(고정): 오른쪽 아래 광학 렌즈 버튼(82dp), 바로 왼쪽 16dp 간격으로 "● TODAY"와 오늘 날짜를 오른쪽 정렬(탭하면 이번 달로). 상단 구분선·알약 배경·별도 카메라 아이콘·촬영 문구 없음. 짙은 광학 유리·푸른 반사·얇은 금속 링으로 렌즈를 표현하며 누르면 바로 커스텀 카메라. 달력은 그룹 위에서 스크롤. 홈 렌즈 외곽에는 얇은 반사광이 4.2초마다 일정 속도로 한 바퀴 흐르는 연속 애니메이션(휴지·페이드 없음) 적용
- 날짜 아래에 오늘 남은 시간을 `HH:mm:ss` 모노 숫자로 표시. 현재 기기 시간대의 다음 자정까지 실제 남은 시간을 초마다 갱신.
- 탭 동작: 사진 있는 날짜 → 기록 상세 / 오늘(기록 없음) → 카메라 / 오늘(기록 있음) → 기록 상세
- 기록 화면은 달력으로 고정. 보기 모드 선택·갤러리·타임라인과 마지막 모드 저장은 제거(2026-11-06).
- 상세·설정에서 돌아오면 달력 스크롤을 유지하고, 촬영 성공 시 이번 달의 오늘 날짜로 이동한다.

### 02 커스텀 카메라

- 프리뷰 오른쪽 아래에 기기 현재 시간을 24시간제 `HH:mm:ss`로 매초 표시한다. 16sp 오렌지(#F08A3C) 모노 숫자와 어두운 그림자, 작은 여백을 사용한다. 셔터를 누른 순간의 시각을 고정하고 필름 효과 적용 후 사진 픽셀에 직접 각인한다. 필름 없음에도 시간은 남고, 흑백 필름에서도 시간은 오렌지다. 썸네일·상세·홈 이동 연출도 같은 각인을 표시한다. 기존 사진에는 소급 적용하지 않는다.

- 공통 CMP `CameraScreen` + iOS AVFoundation / Android CameraX
- 좌상단 닫기, 3:4 프리뷰(모서리 20dp 라운드, 좌우 12dp 여백, 주변은 선택한 테마 배경), 네 모서리 오렌지 브래킷과 중앙 초점 표시
- 줌 눈금 다이얼: 현재 배율, 고정된 오렌지 바늘, 좌우 드래그로 연속 줌. 눈금은 배율의 비율(로그) 간격이라 같은 거리를 밀면 어디서든 같은 비율로 변하고, 손을 떼면 관성으로 흐르다 멈춘다. 라벨은 0.5 · 1 · 1.5 · 2 · 3 · 4 · 5 · 6×, 라벨 눈금을 지날 때 가벼운 햅틱
- 기기 지원 범위 안에서 0.5×–6×. 지원하지 않는 초광각은 노출하지 않으며 고정 mm 환산 표시는 하지 않음
- 하단 중앙 셔터(홈과 같은 광학 렌즈 디자인, 80dp), 그 오른쪽에 필름 버튼(현재 선택한 필름통 이미지 + 필름 이름). 갤러리 버튼 없음
- 필름 버튼을 누르면 줌 눈금 자리에 필름 타일 목록이 나타난다(셔터 위치 고정). 선택 즉시 실시간 프리뷰에 같은 색이 적용되고 프리뷰 좌하단에 모노 칩(VINTAGE / MONOCHROME / WARM / CLEAR / FADE / NATURAL)이 뜬다. 다시 누르면 줌 눈금으로 돌아간다
- 필름: "필름 없음"(기본, 원본 그대로) · 빈티지(입자 + 비네팅, 색은 그대로) · 흑백(고정 명암 + 입자 + 비네팅) · 온기(따뜻한 색·약한 입자·비네팅) · 청명(미세한 푸른빛·대비) · 바램(들뜬 검정·절제된 채도·입자) · 내추럴(아주 약한 온기·채도 절제). 필름 없음까지 7개 선택지를 72dp 타일의 가로 스크롤 목록에 표시한다. 목록을 다시 열면 현재 선택 필름이 보이도록 한다. 기존 테스트 필름은 새 촬영 목록에서 제외하고 과거 기록의 이름 해석만 유지한다. 강도는 필름마다 고정. 필름은 색상 행렬과 질감(입자·비네팅) 수치로 정의해 프리뷰와 저장 결과가 같다
- 필름 선택 아이콘은 공통 필름통 이미지. 필름 없음은 검정 무지, 빈티지는 오렌지, 흑백은 무채색, 온기는 꿀빛, 청명은 하늘색, 바램은 연한 자주색, 내추럴은 세이지색 라벨. 선택한 이름 아래 번트 오렌지 밑줄을 표시한다.
- 촬영 성공 → 바로 저장 후 홈 복귀. 카메라가 닫히는 순간 뷰파인더의 사진이 그 자리에서 곧바로 작아지며 달력의 오늘 칸으로 들어간다. 중간에 머무는 화면이나 어두운 배경, 대기 창은 없다. 닫기 → 저장 없이 복귀하며 기존 기록을 변경하지 않음
- 카메라 권한 거부 → 안내창으로 설정에서 권한을 켜도록 안내(대체 입력 경로 없음). 촬영 중 에러 → 프리뷰 자리에 안내
- 진입 경로: 홈 촬영 버튼, 오늘 날짜 탭(기록 없을 때), 오늘 기록 상세의 사진 변경. 어느 경로든 기록 날짜는 항상 오늘

### 03 기록 상세

- 큰 사진, 모노 메타 라인(날짜·요일·필름 이름), 명조 날짜 "9월 20일, 일요일", 선택적 한 줄 메모(120자)
- 메모가 없으면 "오늘을 한 줄로 남겨보세요" 플레이스홀더. 탭하면 컴팩트 모드로 전환해 키보드 공간 확보
- 사진 변경은 오늘 기록에서만 노출: 교체 확인 → 카메라로 다시 촬영 → 바로 교체 저장. 지난 기록은 메모 편집과 삭제만
- 삭제: 확인 후 영구 삭제. 지난 기록은 삭제하면 그 날짜를 다시 채울 수 없음을 확인창에 명시
- 상세 화면에는 사진 스와이프 이동과 하단 이전·다음 버튼을 두지 않음. 다른 기록은 홈 달력에서 선택

### 04 설정 및 하단 탭 (2026-10-25)

- 기록 / 필름 / 설정 세 탭. 기록 탭은 책(일기장) 아이콘으로 표시. 홈은 달력과 촬영 버튼을 제공한다.
- iOS: SwiftUI 네이티브 탭바, iOS 26 이상 Liquid Glass. 이전 iOS는 기본 네이티브 스타일.
- Android: Material 3 하단 내비게이션, 패널 배경과 번트 오렌지 선택 표시.
- 설정: 명조 제목·모노 섹션 라벨·얇은 구분선과 라이트 모드 On/Off 스위치.
- 기본 Off(기존 다크). On은 따뜻한 아이보리 팔레트로 홈·상세·설정·카메라 UI를 표시. 선택은 기기에 저장하고 재실행 후 유지한다. 시스템 모드와 독립적이다.
- 카메라도 선택한 라이트/다크 모드를 따른다. 실제 프리뷰·저장 사진과 사진 위 가이드의 색은 UI 테마로 바꾸지 않는다. 홈과 탭바를 최종 위치에 미리 배치하고 전체 화면 스플래시로 덮는다. 사진이 렌즈로 축소되면서 홈·탭바가 함께 드러나며, 전환 완료 전에는 조작할 수 없다. 상세와 카메라에서는 탭바를 노출하지 않는다.

## 저장

- `diary/records.json`(날짜·메모) + 날짜당 사진 한 장(긴 변 최대 2048px, 방향 보정)과 썸네일(180px). 구현은 교체를 원자적으로 하기 위해 폴더 대신 `diary/<날짜>-<id>-photo.jpg` / `-thumb.jpg`처럼 새 이름으로 쓰고 목록을 바꾼다
- 필름이 적용된 사진 한 장만 저장한다. 필름 없는 원본 사본과 강도 필드는 두지 않으며, 기록에는 어떤 필름이었는지 id(`film`)만 남긴다. 없어진 필름 id는 "필름 없음"으로 표시
- 이미지 저장 완료 후 목록을 원자적으로 교체. 실패 시 기존 기록 유지, 임시 파일 정리
- GPS 등 EXIF 메타데이터는 저장하지 않음

## 디자인

벤치마크는 「내가 당신을 사랑할 때 보이는 순간들: 빈티지 카메라앱」. 에셋과 문구는 가져오지 않고 무드만 옮긴다.

- 순흑 위의 사진: 배경 #070706(화면 내부는 #000). 면은 색이 아니라 1px 헤어라인으로 나누고 모서리는 2–4px
- 명조 헤드라인: 제목·본문 모두 명조(Noto Serif KR), 굵기 400/600 두 단계. 현재 구현은 플랫폼 기본 Serif라서 Android는 명조, iOS는 한글이 고딕으로 표시된다(iOS에 한글 명조 시스템 글꼴 없음). 서체 번들 전까지의 임시 상태. "9월, 담아둔 하루"처럼 달 + 쉼표 + 명사구
- 모노 메타데이터: 날짜·배율은 자간 넓은 모노 소형 라벨(예: 2026.09.14 MON, 1.5×)
- 포인트색 번트 오렌지 #D98551은 한 화면에 1–2곳만(오늘 점, 줌 바늘, 뷰파인더 브래킷). 기존 노랑 #E5A62F와 올리브 계열 테마를 대체
- 팔레트: BLACK #070706, PANEL #12110F, TAUPE #5B5548, INK #EDE8DD, MUTED #8F897C, ACCENT #D98551, 날짜 각인 #F08A3C
- 카메라의 물성: 코너 브래킷, 눈금 다이얼, 금속 셔터. 아이콘은 얇은 라인, 버튼은 알약형 아웃라인
- 필름의 흔적: 입자와 비네팅은 앱이 모든 사진에 얹지 않는다. 선택한 필름에 정의된 질감만 저장 단계에서 입혀지고, 상세·달력은 저장된 사진을 그대로 보여 준다
- 문구: 짧은 평서문, 시처럼 한 줄. 느낌표와 이모지는 쓰지 않음
- 사진 중심. 홈 / 설정 두 탭만 제공하며 메뉴를 불필요하게 늘리지 않음
- 참고 시안: 스토리보드 `index.html`이 기준. design/daily-photo-design.html, design/photo-filter-design.html은 이전 방향의 기록으로만 보관
- 스토리보드 속 사진은 구도 확인용 그라데이션이며 실제 색감이 아님

## 미확정

- 신규 필름 4종의 장면별 색감 튜닝은 실기기 검토 후 진행. 2026-11-09 사용자 요청으로 온기·청명·바램·내추럴을 앱에 추가

## 필름 진열장 (2026-10-30)

기록 / 필름 / 설정의 3탭. 필름 탭은 빈티지·흑백·온기·청명·바램·내추럴 필름통을 2열·3행으로 보여주고, 탭하면 커피 예시와 원본을 비교하는 바텀시트를 연다. 제목은 필름 진열장. 필름 없음 행과 하단 감성 문구는 제외한다. 둘러보기는 카메라의 필름 선택을 바꾸지 않는다.
