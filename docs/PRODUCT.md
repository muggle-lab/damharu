# 제품 및 디자인 결정

## 확정 사항

- 이름: 담하루
- 스토어 이름 후보: 담하루 — 하루 한 장 사진 일기
- 핵심 문구: 사진 한 장이면, 오늘의 기록은 끝.
- 대상: 일기나 브이로그는 부담스럽지만 사진 한 장으로 하루를 남기고 싶은 사람
- 개인 기록 전용. 서버·계정·로그인 없이 로컬 저장
- KMP + CMP 학습과 실제 앱 개발을 병행
- iOS 구현 후 Android 구현

## 기록 흐름

홈 달력 → 사진 선택 또는 촬영 → 사진 확정 및 선택적 필터 → 저장 → 홈 달력

사진만 저장해도 완료. 저장 후 메모 입력을 요구하지 않는다. 기록한 날짜를 누르면 상세 화면에서 사진을 크게 보고 선택적으로 한 줄을 남긴다.

## 화면

### 홈 달력

- 월 제목, 요일, 날짜별 대표 사진
- 오늘 한 장 남기기 버튼
- 오늘 저장 후 ‘오늘을 남겼어요’ 상태와 오늘의 사진 접근
- 빈 날에 실패/미완료 표시, 연속 기록 압박 없음
- 과거 날짜 기록 가능
- 첫 사용 문구: 오늘, 기억하고 싶은 장면 하나.

### 사진 선택 및 촬영

- 오늘 사진 중심으로 탐색하고 전체 사진에서도 선택 가능
- 시스템 사진 선택기와 촬영 API 활용 방향
- 선택/촬영 취소 시 기존 기록을 변경하지 않음
- 과거 기록을 위해 기록 날짜 변경 가능

### 사진 확정 및 필터

- 큰 사진 미리보기, 하단 필터 썸네일
- 원본이 기본. 추가 조작 없이 저장 가능
- 원본 / 온기 / 맑음 / 필름 / 흑백
- 필터 선택 시 강도 슬라이더와 원본 비교 노출
- 원본 버튼: 이대로 남기기
- 필터 적용 버튼: 이 사진으로 남기기
- 원본을 보존하고 필터 종류·강도를 기록하는 구현 방향
- 미리보기와 최종 저장 이미지의 색감 일치 검증 필요

### 기록 상세

- 날짜와 큰 사진, 선택적 한 줄 메모
- 글이 없으면 비어 있는 입력 상자를 노출하지 않음
- 사진 변경, 기록 삭제
- 좌우로 다른 기록 탐색

## 디자인

- 밝은 모드 기준 배경 #F8F7F2, 본문 #30372E, 보조 글자 #74786D, 올리브 #54644A
- iOS 시스템 서체, 넉넉한 여백, 절제된 모서리
- 사진 중심. 탭바나 메뉴를 불필요하게 늘리지 않음
- 참고 시안: design/daily-photo-design.html, design/photo-filter-design.html
- 시안 속 이미지는 구도 확인용 일러스트. 필터 색감은 실제 사진으로 별도 조정
- 시안의 저장 완료 전용 화면은 상태 표현 참고용이며, 기본 흐름은 저장 후 홈 복귀

## 나중에 다룰 항목

월별 모아보기, 앱 잠금, 리마인더, 백업/내보내기. 초기 범위에 자동 포함하지 않는다.

## 구현 시 결정할 항목

앱 식별자·서명, 라이브러리 버전, 로컬 DB 방식, 이미지 해상도 정책, 동일 날짜 기록 교체 확인, 삭제 확인 UX. 이름의 상표·스토어 중복 여부는 아직 확인하지 않음.
